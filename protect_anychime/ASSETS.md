## Audio

No Ubiquiti ringtone, firmware sound or confirmation recording is distributed in this source tree. The running app receives default and custom ringtone bytes from the user's own Protect console using its native chime synchronization protocol. Those files live only in installation-specific HA app data. Test audio inputs are synthetic and generated by test helpers.

## UniFi client artwork (0.3.26)

Client metadata source: https://static.ui.com/fingerprint/0/devicelist.json
Small client images: https://static.ui.com/fingerprint/0/{id}_129x129.png
Artwork is fetched on demand from the fixed official HTTPS host and cached in
`/data/product-images`; no controller credentials are sent to the image host.
Related-model substitutes are explicit. One SL uses the available Sonos One image;
Beam Gen 2 uses the available Sonos Beam image. Reported HA model details are kept.
